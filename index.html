Paste from Docs, Word, Pages or Notes, or upload a Word or PDF file. Headings become lines starting with "#", bold becomes **bold**, italic becomes *italic*. You can type these marks yourself too.

Sync with GitHub (optional, to share the script between devices)

Saves the script as a file in your repo. Use a fine-grained token limited to that one repo with Contents: read and write. Enter these once on each device. If the repo is public, the script is public too.
